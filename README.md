# かけいぼ

シンプルな家計簿アプリ。カテゴリ(大項目→小項目)は自由に設定できます。

- 例: 食費 → 外食、スーパー

ビルド不要の静的サイト(HTML / CSS / 素のJavaScript)です。

## 画面

- **入力** — 収入/支出、大項目・小項目、金額、メモを入力
- **履歴・集計** — 月を選んで収入・支出・収支と大項目別の支出内訳、取引一覧を確認
- **カテゴリ設定** — 大項目・小項目の追加/削除

## データの保存について

データはブラウザの localStorage に保存されます(このアプリ専用のサーバーやデータベースはありません)。
そのため:

- 同じブラウザ・同じ端末でアクセスする限りデータは保持されます
- ブラウザやシークレットモードが変わるとデータは共有されません
- ブラウザの「サイトデータを削除」操作を行うと消えます

## ローカルで開く

`index.html` をブラウザで直接開くだけで動作します。ビルドや `npm install` は不要です。
